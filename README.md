# 14 Red Door

The 14 Red Door website built using Bridgetown, a modern, Ruby-based static site generator. This project serves as an example for a well-structured, performant, and maintainable website with a focus on clean design and efficient development workflows. It is live at [14rd.com](https://14rd.com/)

## Features

* Bridgetown-Powered: Utilizes Bridgetown for fast, flexible, and scalable static site generation.
* Component-Based Architecture: Uses Bridgetown components for reusability and maintainability.
* Responsive Design: Ensures a seamless experience across various devices.
* Tagging System: Tag categorization with custom filters.
* Optimized Image Handling: Responsive images for better performance.
* COMING SOON: SEO Optimization: Structured data and meta tags for better search visibility.
